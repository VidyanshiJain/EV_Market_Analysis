# Electric Vehicle Market Performance & Insights

## 📌 Overview
This repository contains the complete documentation and interactive visualizations for the Electric Vehicle (EV) Market Performance & Insights project. The project analyzes a massive dataset (200,000+ rows) to uncover key insights into EV market performance, battery technologies, annual sales trends, and global distribution.

## 📁 Project Documentation (Phase-wise)
All project phases have been thoroughly documented and are available as PDF files in this repository:
1. **Ideation Phase:** Problem Statement, Empathy Map, and Brainstorming.
2. **Requirement Analysis:** Customer Journey Map, Solution Requirements, Data Flow, and Tech Stack.
3. **Project Design Phase:** Problem-Solution Fit, Proposed Solution, and Architecture.
4. **Project Planning Phase:** Project Planning Template and scheduling.
5. **Project Development Phase:** Preprocessing Steps, Business Questions, HD Screenshots, and Dataset context.
6. **Performance Testing:** Amount of data rendered, utilization of filters, and rendering performance.
7. **Doc and Demo:** Final Report and Project Demonstration Video link.
